Python To-Do List Interaktif

Proyek pertama saya dalam belajar Python: program daftar tugas berbasis terminal yang berjalan terus-menerus sampai pengguna memilih keluar.

Python List While loop If / Elif Input pengguna

Cara kerja

  1. Program menyimpan semua tugas di sebuah list bernama todo_list.
  2. Lewat loop while True, program menampilkan daftar tugas (atau pesan kosong jika belum ada tugas), lalu menu pilihan.
  3. Pengguna memilih: 1 untuk menambah tugas, 2 untuk menghapus tugas terakhir, 3 untuk keluar.
  4. Setiap aksi langsung memperbarui daftar, lalu menu tampil lagi sampai pengguna memilih keluar.

Kode lengkap

todo_list = []

while True:
  if not todo_list:
    print("Your ToDo list is empty")
  else:
    index = 1
    for task in todo_list: 
      print(f"{index}. {task}")
      index += 1

  print("Options:")
  print("1. Add Task")
  print("2. Remove Task")   
  print("3. Quit")

  choice = input("Enter your choice (1, 2, or 3): ")

  if choice == "1":
    print("Adding task")
    new_task = input("Enter the task: ")
    todo_list.append(new_task)
    print(f"Task '{new_task}' added to the ToDo list")
  elif choice == "2":
